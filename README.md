# 🌟 RememberThat – Task App Landing Page

A sleek and responsive **task management landing page** built with **HTML, SCSS/CSS, and JavaScript**.  
Designed to demonstrate modern frontend design and responsive layouts.

## ✨ Features
✅ Fully responsive navigation bar with mobile toggle  
✅ Modern hero section with call-to-action buttons  
✅ Highlighted features list with visuals  
✅ Testimonials section for user feedback  
✅ Contact form with embedded Google Map  
✅ Lightweight JavaScript for menu animations  

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the webpage  
- **SCSS → CSS3** – Styling and responsive design  
- **Vanilla JavaScript** – Mobile menu toggle
